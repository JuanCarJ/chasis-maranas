# Demo web — Chasis Marañas

Landing pública conceptual para presentar los servicios de soldadura, alineación y reparación estructural de Chasis Marañas en Marinilla.

## Ejecutar localmente

Desde esta carpeta:

```bash
python3 -m http.server 4174
```

Luego abrir [http://127.0.0.1:4174/](http://127.0.0.1:4174/).

## Producción

La demo está publicada en [https://chasis-maranas.vercel.app/](https://chasis-maranas.vercel.app/) mediante el proyecto Vercel `chasis-maranas`.

## Alcance de esta demo

- Página estática responsive, sin backend ni formulario que envíe datos.
- CTAs directos al enlace público de WhatsApp.
- Enlaces a Instagram y TikTok del taller.
- Mapa embebido de Google Maps para Cl. 26 #34-83, Marinilla, Antioquia.
- Imágenes generadas para concepto, marcadas como tales en la interfaz.

Antes de publicar, reemplazar las imágenes conceptuales por fotografías reales autorizadas y confirmar teléfono, horarios, logo y punto exacto del taller.
